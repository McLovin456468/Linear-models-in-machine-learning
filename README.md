# Проект: Отбор коров по прогнозу удоя и вкуса молока

## 1. Назначение и цель проекта

Фермер планирует расширение поголовья стада и заключает контракт на покупку коров. Необходимо объективно оценивать животных, так как продавцы могут завышать их характеристики.

**Цель проекта:** разработать две модели машинного обучения для отбора коров по критериям:

1. **Регрессионная модель** — прогнозирование годового удоя коровы (в килограммах).
2. **Классификационная модель** — расчёт вероятности того, что молоко соответствует вкусовым критериям фермера (бинарный признак).

**Условия отбора коров:**
- средний удой за год — **не менее 6000 кг**;
- молоко должно быть **вкусным** (по классификации фермера).

## 2. Входные данные

### 2.1. Файлы данных

| Файл | Описание |
|------|----------|
| `ferma_main.csv` | Данные о текущем стаде фермера (обучение моделей) |
| `ferma_dad.csv` | Имена отцов коров из текущего стада |
| `cow_buy.csv` | Данные о коровах, рассматриваемых для покупки |

### 2.2. Структура `ferma_main.csv`

| Поле | Описание |
|------|----------|
| `id` | уникальный идентификатор коровы |
| `Удой, кг` | масса молока в год (кг) — **целевой признак (регрессия)** |
| `ЭКЕ` | энергетическая кормовая единица (показатель питательности корма) |
| `Сырой протеин, г` | содержание сырого протеина в корме (граммы) |
| `СПО` | сахаро-протеиновое отношение |
| `Порода` | порода коровы |
| `Тип пастбища` | ландшафт пастбища |
| `порода папы_быка` | порода отца коровы |
| `Жирность,%` | содержание жиров в молоке (%) |
| `Белок,%` | содержание белков в молоке (%) |
| `Вкус молока` | оценка вкуса (вкусно / не вкусно) — **целевой признак (классификация)** |
| `Возраст` | возраст: менее_2_лет / более_2_лет |

**Группы признаков:**
- Характеристики коровы: `id`, `Порода`, `порода папы_быка`, `Возраст`
- Характеристики корма: `ЭКЕ`, `Сырой протеин, г`, `СПО`
- Характеристика пастбища: `Тип пастбища`
- Характеристики молока: `Удой, кг`, `Жирность,%`, `Белок,%`, `Вкус молока`

### 2.3. Структура `ferma_dad.csv`

| Поле | Описание |
|------|----------|
| `id` | уникальный идентификатор коровы |
| `Имя Папы` | имя отца коровы |

### 2.4. Структура `cow_buy.csv` (данные для прогноза)

| Поле | Описание |
|------|----------|
| `Порода` | порода коровы |
| `Тип пастбища` | ландшафт пастбища |
| `порода папы_быка` | порода отца |
| `Имя_папы` | имя отца |
| `Текущая_жирность,%` | содержание жиров в молоке на момент продажи |
| `Текущий_уровень_белок,%` | содержание белков в молоке на момент продажи |
| `Возраст` | возраст (менее_2_лет / более_2_лет) |

**Особенности `cow_buy.csv`:**
- Отсутствуют параметры корма (`ЭКЕ`, `Сырой протеин, г`, `СПО`) — их значения берутся из `ferma_main.csv` (средние) и увеличиваются на 5%.
- Отсутствуют целевые признаки (`Удой, кг`, `Вкус молока`) — их предсказывают модели.
